## Current Site State

- **What's there:** A homepage with roughly 200 words, a contact form attracting spam, no dedicated service pages, no location pages, no blog, no schema markup, and an H1 that reads "About Us."
- **What's missing:** Everything that drives organic traffic — service pages, location pages, informational content, correct title tags, LocalBusiness schema, a Google reviews feed, a real About page, and a prominent click-to-call.
- **Biggest opportunity:** "Control4 installer Blackpool" returns zero local competitors in organic search. Wilsons Systems is the only authorised dealer on the Fylde Coast. A single well-optimised page could own this query entirely. At the higher end, smart home projects run £5,000–£50,000+.

## How This Maps to the Rora Skills Process

This assessment was produced as a demonstration of sequential skill application to a single client brief. The flow is:

**1. Brand first**
Get the voice and visual direction right before writing a word of copy. For Wilsons: confident trade professional, accreditation-led trust, plain-spoken premium. The 4-axis framework locks this in so that every piece of future copy — by Ryan, by a copywriter, by a marketing agency — sounds like the same business.

**2. Architecture second**
Decide what pages exist and how they connect before writing any of them. The sitemap is simultaneously a brief to the developer, a map for the SEO strategist, and a navigation spec for the UX designer.

**3. Keywords third**
Know what each page needs to rank for before writing its title or body. The keyword clusters in File 3 map directly to the sitemap in File 2. Every page has a primary keyword and a secondary keyword. Nothing is written without a reason.

**4. Copy fourth**
Write with the voice spec and keyword targets simultaneously in hand. The homepage copy in File 4 reads naturally, uses the correct terms in the correct density, and has a clear conversion structure. It does not read like an SEO brief; it reads like a business talking to a customer.

**5. On-page fifth**
Systematically optimise every page's metadata once the copy exists. Title tags and meta descriptions are short, keyword-led, and written to earn the click — not just to satisfy a word count.

**6. Technical last**
Fix the infrastructure that lets everything else work. Schema, speed, HTTPS, sitemap, mobile — these are the floor, not the ceiling. Get them right and Google can do its job. Get them wrong and everything above this layer is undermined.

Each skill can be applied independently for clients who need only one layer, or run in full sequence as shown here for clients starting from scratch.
