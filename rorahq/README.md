## What this is

A systematic pass through 8 skills from the Claude Skills library, applied to Rora from the ground up. Each file is both a Rora deliverable and a template for client work (The Skinician, future prospects).

The brand foundation was already locked before this pass (name, purpose, positioning, tagline, personality). This walkthrough picks up at aesthetic direction and works through to technical SEO.

## Why this order

Each step feeds the next. You cannot write good copy without aesthetic direction. You cannot audit voice without knowing the standard. You cannot optimise on-page SEO without knowing what keywords you're targeting. Start at 01 and work forward.

---

## Reusing for client work (The Skinician, others)

1. Replace Rora context with client brief
2. Run `creative-direction` fresh — the 4-axis questions surface the client's aesthetic direction
3. Skip `logo-design` if client has a logo — replace with a logo audit (does it scale? does it reverse?)
4. `brand-voice-audit` adapts directly — use client's existing copy as the audit source
5. `landing-page-copy` adapts directly — swap offer, audience, proof points
6. SEO steps adapt directly — swap geography and service terms

Minimum viable client pass: steps 01, 03, 05, 06, 07, 08.
